The UX of HTML: Basics

Headings

Why a Proper Heading Structure Matters

  • Screenreaders use headings as a table of contents so they can jump directly to sections
  • Skipping levels confuses blind users
  • It improves SEO (Search Engine Optimization)
  • It makes the document cleaner and easier to style with CSS
  • It's easier to maintain and update

How you can have a page's heading structure display or read aloud by a tool

You can use an extension like HeadingsMap that visualizes the heading of a page, or use another browser like Polypane.

Images

What UX do I think is better?

I think the best UX is when the a tag does not have an alt attribute and only the image has an alt attribute.

The different ways in which you can use images and what sort of alt attributes go with each

  • Decorative images: alt=""
  • Informative images: alt="Description of the image" (without "image of")
  • Functional images (like buttons): alt="Function of the button"

What I learned about alt tags

They are very important to people that can't see or are hard of seeing. They are also important for SEO. You shouldn't use the same alt tag for multiple images, and you should put an empty alt tag for decorative images.

Landmarks & Regions

What are landmarks and what is their relation to semantic elements

A landmark is a section of a web page that allows screen readers etc. to create dynamically generated summaries of a page's layout. It allows fast navigation. They map directly to specific ARIA landmarks.
