## How to answer

Add your diagrams and answers below the corresponding tasks. Provide explanations only where the question asks for them.

Use a modeling tool given on leho. Export readable diagrams as JSON, PNG or SVG files, store them in an `images/` folder in your group's repository, and embed them in the relevant answer file using relative paths. Include editable source files when your tool supports them. Replace each diagram placeholder with your own diagram.

Review the complete workbook together before submitting.

## How to submit

Keep this readme.md, answers.md, and the answers/ folder together at the root of your group's workshop repository in the [Howest DDD GitHub organization](https://github.com/howest-ti-ddd). If you received this workshop in an existing repository, complete it there.

Commit and push the completed workbook, diagram exports, and any editable diagram source files. These files form your group's report.

Use the deadline and any submission-link requirements announced by your lecturer on the course platform. If a submission link is requested, provide the repository URL and the final commit identifier so the submitted version can be identified.
